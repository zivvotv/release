# Zivvo

Downloads for Zivvo: the server plugin for Jellyfin and Emby, and the Android and Android TV apps.

## Jellyfin plugin

Add this repository URL to your Jellyfin plugin repositories (Dashboard > Plugins > Repositories):

```
https://raw.githubusercontent.com/zivvotv/release/refs/heads/master/manifest.json
```

Then install **Zivvo** from the plugin catalog.

## Emby plugin and apps

Download them from the [releases](https://github.com/zivvotv/release/releases).
